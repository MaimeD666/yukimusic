# Проверки 0.1

`scripts/test.ps1` запускает проверку Svelte/TypeScript, проверки контраста палитр, частотной избирательности и огибающей баса, а также Rust-тесты очереди, DSP, HTTP Range, кэша и сохранения данных.

Нативные сценарии требуют отдельного `YUKICLOUD_DATA_DIR`, Python Playwright, WebView2 и `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222`. Они меняют очередь, громкость, коллекцию и размеры окна. Используйте тестовый профиль, не личный. В обычном запуске порт отладки не открывается.

- `scripts/smoke.py`: настоящий поиск, полный плейлист, все страницы артиста, воспроизведение, очередь, EQ, сохранение.
- `scripts/latency-smoke.py`: старт, перемотка, следующий трек, пауза, пропуск подтверждённо недоступных дублей, автоматическая подгрузка. Подготовьте `.tools/before-speed-test.json` со снимком тестовой очереди.
- `scripts/window-smoke.py`: 49 проверок размеров HWND, клиентской области и WebView, обычное/развёрнутое/мини/полноэкранное окно, быстрые повторные команды. Нужен выбранный трек на паузе.
- `scripts/performance.py`: суммарная память и CPU всей группы процессов, полноэкранный бас, выгрузка WebView в трее, продолжение музыки и восстановление окна. Требует `psutil`, который также можно установить в `.tools/python`.

Точный тест декодирования требует в тестовой коллекции хотя бы один доступный трек:

```powershell
$env:YUKICLOUD_TEST_PROFILE = 'C:\path\to\test-profile'
cargo test --manifest-path src-tauri/Cargo.toml real_seek_buffers_match_decoded_position -- --ignored --nocapture
```

Для 0.1 прошли 20 обычных Rust-тестов и этот отдельный сетевой тест. Для MP3 и HLS обнаруженное смещение после перемотки относительно полного декодирования составило 0 сэмплов. Нативная проверка повторного открытия выхода сохранила трек, позицию, паузу, громкость и EQ; кнопки превью Windows проверены через сообщения thumbnail toolbar. Реальное физическое отключение всех доступных устройств в автоматической проверке не выполнялось.

Визуальная проверка баса на мониторе 165 Гц: 412 кадров за 2,5 секунды, медианный интервал 6,1 мс. На паузе трансформация обложки полностью сбрасывается. Windows 11 отдельно на этой машине не проверялась; сборка предназначена для Windows 10/11 x64.
