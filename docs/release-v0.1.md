Первый публичный выпуск yukicloud. Музыка, немного готики и бас, который теперь видно.

**Windows 10 / 11, x64.**

- `yukicloud_0.1.0_x64-setup.exe` — обычная установка. При необходимости установщик загрузит Microsoft WebView2.
- `yukicloud_0.1.0_x64-portable.zip` — распаковать целиком и запустить `yukicloud.exe`. Папка `resources` должна оставаться рядом; WebView2 нужен и здесь.
- `SHA256SUMS.txt` — контрольные суммы.
- `ffmpeg-8.0.1.tar.xz` — соответствующий исходный код включённого аудиодекодера. Для прослушивания скачивать его не нужно. Инструкции сборки находятся в репозитории.

Поиск артистов, плейлистов и треков в одном окне; локальная коллекция; очередь; эквалайзер; мини-плеер поверх окон; полноэкранный плеер с палитрой обложки, спектром и отдельным бас-режимом. Превью на панели задач поддерживает предыдущий трек, паузу и следующий. При смене устройства Windows звук переходит на новый выход с сохранением позиции.

Крестик убирает приложение в трей. Через 30 секунд скрытый интерфейс выгружается, музыка продолжает играть. Полный выход — через меню трея.

Это неофициальный клиент публичного API v2 SoundCloud. Коллекция хранится локально, входа в аккаунт и офлайн-загрузки нет. Доступность треков зависит от SoundCloud и региона.
